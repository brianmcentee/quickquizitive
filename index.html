THE GOOD-TO-KNOWS

A little clarity.

A small, independent helper.
No account or subscription required.

Is it really free?+

Yes. This version is free to download and use. You don’t need an account or an AI API key.

Does downloading install it automatically?+

No. This is a manual installation, not a Chrome Web Store listing. Follow the four steps above. Downloading the ZIP alone does not install or run it.

Which questions are supported?+

The helper supports observed multiple-choice, True/False, dropdown, correct/incorrect card, matching, and image-hotspot formats. It has been tested on one InQuizitive assignment; compatibility with every course or activity is not guaranteed. Unsupported formats stop the run.

What happens after 100%?+

The helper asks whether you want to continue after the assignment displays its maximum grade of 100%. Cancel stops the run. Confirm allows extra questions until you stop it or it encounters an issue.

What does it access?+

The extension reads question data and uses controls on the active InQuizitive page. It does not send course content to an external AI service, directly modify scores, or alter recorded timing. The current build makes no external network requests.

What if the helper stops or an update is available?+

Unsupported questions, unfamiliar dialogs, lost points, or a progress timeout stop the runner. You can continue manually. Updates are currently manual: download the new package, replace the extension files, reload QuickQuizitive at chrome://extensions, and refresh the assignment.
