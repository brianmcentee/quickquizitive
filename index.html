THE GOOD-TO-KNOWS

A little clarity.

A small, independent helper.
Google sign-in. A free monthly allowance.

Is it really free?+

The free plan includes 3 distinct assignments per UTC calendar month. Sign in with Google to use it. Restarting the same authorized assignment within that month does not consume another use. No AI API key is required.

Does downloading install it automatically?+

No. This is a manual installation, not a Chrome Web Store listing. Follow the four steps above. Downloading the ZIP alone does not install or run it.

Which questions are supported?+

The helper supports observed multiple-choice, True/False, dropdown, correct/incorrect card, matching, image-hotspot, passage-selection, ordering, and diagram drag/drop formats. It has been tested on parts of two InQuizitive assignments; compatibility with every course or activity is not guaranteed. Unsupported formats stop the run.

What happens at 100%?+

The runner stops automatically when the assignment displays 100%. Starting an already-completed assignment does not consume an allowance.

What does it access?+

The extension reads question data and uses controls on the active InQuizitive page. It does not send course content to an external AI service, directly modify scores, or alter recorded timing. Google and Supabase handle sign-in and assignment allowances. Only account/session information and assignment identifiers are needed by the backend; Norton passwords and question content are not sent to it. See our privacy policy.

What if the helper stops or an update is available?+

Unsupported questions, unfamiliar dialogs, lost points, or a progress timeout stop the runner. You can continue manually. The panel checks for new releases and links to the download page. ZIP updates remain manual: download the new package, replace the extension files, reload QuickQuizitive at chrome://extensions, and refresh the assignment.
